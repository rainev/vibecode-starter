# Your business data

`business.json` holds every word on your website as **JSON objects**. JSON is a simple way to write data with `"key": "value"` pairs inside `{ }`, and lists inside `[ ]`.

Try prompting: *"Change business.json to a milk tea shop called Boba Bay in Makati, with four features."*

> ⚠️ **Workshop limitation:** We store data in JSON files instead of a real database. That keeps things simple for the workshop, but it isn't how a full-scale app works. See "Limitations" in the main README.
